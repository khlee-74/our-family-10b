# OUR FAMILY 10B

YULIM Infotech 공식 로고를 포함한 가족용 오프라인 우선 자산관리 웹앱입니다.

## GitHub Pages 배포
1. GitHub에서 `our-family-10b`라는 새 Public 저장소를 만듭니다.
2. ZIP을 풀어 안의 파일과 `assets` 폴더를 저장소 최상위(root)에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
4. 잠시 후 `https://계정명.github.io/our-family-10b/`로 접속합니다.

## 기능
- 가족 4명 프로필과 개인별 자산·부채 입력
- 가족 순자산과 10억 목표 진행률
- 저축 기록 및 월별 현황
- 매일 3분 경제 습관
- 가족 미션
- 경제 공부 9개 주제
- 2036 목표와 점검 기록
- 나눔 아이디어·실천 기록
- 가족 성장 연대기
- JSON 백업·가져오기

## 중요한 데이터 안내
- 데이터는 해당 브라우저의 localStorage에 저장됩니다.
- 서버가 없으므로 기기 간 실시간 자동 동기화는 되지 않습니다.
- 기기 변경, 브라우저 초기화 전에는 반드시 JSON 백업을 하세요.
- 여러 기기의 백업을 합칠 때는 각 기기에서 최신 백업을 내보내고 한 기기에서 가져오세요.
- 금융 계정 비밀번호, 주민등록번호, 계좌번호 등 민감정보는 입력하지 마세요.
- 자산은 같은 기준일의 현재 가치로 입력하고, 대출은 부채로 입력하세요.
- 저축 기록은 현금흐름 기록이며 자산에 다시 더하지 마세요. 예금 등을 자산 항목에 등록하면 순자산에 반영됩니다.

## 비용 및 보장
정적 웹앱으로 서버·유료 AI 연결 없이 사용할 수 있도록 제작했습니다. GitHub Pages의 서비스 정책과 이용 가능 여부는 별도로 확인하세요. 앱은 기록·계획 도구이며 자산 목표 달성이나 투자수익을 보장하지 않습니다.
